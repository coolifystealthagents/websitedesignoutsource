# A Breadcrumb Review Checklist for Outsourced Website Design

Breadcrumbs are useful when they reflect a meaningful hierarchy. They should help visitors understand where a page belongs without replacing primary navigation or becoming a row of confusing links.

## Confirm the hierarchy

Compare each breadcrumb with the approved information architecture. If the route is not truly nested, a breadcrumb may add noise rather than context.

## Use clear labels

Labels should match the page title or an agreed short form. Avoid unexplained abbreviations and make each parent destination useful on its own.

## Check the final item

Decide whether the current page is plain text or a link based on the interaction. Make the current location clear to screen reader and sighted users.

## Review narrow layouts

Test long labels, wrapping, truncation, keyboard focus, and small screens. Preserve the hierarchy even if the visual presentation changes.

## Frequently asked questions

### Should every page have breadcrumbs?

No. Use them where the hierarchy helps visitors orient themselves and the parent destinations are meaningful.

### Are breadcrumbs a substitute for menus?

No. They support orientation within a hierarchy; primary navigation still needs to expose the site’s main paths.
