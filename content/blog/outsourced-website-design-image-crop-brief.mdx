# Image Crop Rules for an Outsourced Website Design Brief

An image can look correct in a design file and fail when the container changes shape. A crop brief gives the outsourced website design team a subject, a safe area, and a fallback instead of asking for a particular screen capture.

## Name the focal point

Describe what must remain visible and what may be removed. If a person, product detail, or piece of text is essential, mark it in the source asset or brief. Do not assume the center of an image is always the right crop.

## Define the container behavior

State whether the image should cover, contain, or keep a natural ratio. Show a narrow and wide example when the crop affects meaning. Include the minimum useful dimensions and the intended alternative text, but let the content owner approve that text.

## Plan for missing assets

Record what happens if the image is delayed, unavailable, or unsuitable for a smaller crop. A page should retain its heading and action when the image is removed. The design should not make a decorative asset a requirement for understanding the page.

## Hand off the source

Keep the original asset, approved crop, license note, alt text, and page usage together. The outsourced website design team should return the crop rule and any derivative files so a future editor can reproduce the treatment.
