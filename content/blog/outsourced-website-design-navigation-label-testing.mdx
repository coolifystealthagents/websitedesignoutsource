# Testing Navigation Labels Before an Outsourced Website Launch

List the main tasks the site supports, then compare candidate labels against those tasks. Prefer familiar nouns over clever campaign language when the label must work without surrounding context.

## Test recognition

Ask reviewers to predict what each label contains and where they would find a specific piece of information. Record confusion separately from preference, because a familiar label can still be too broad.

## Preserve route clarity

Keep labels, page titles, breadcrumbs, and links aligned. If a page changes name late in the project, review redirects and internal links as part of the same decision.

## Frequently asked questions

### Why include this in an outsourced design brief?

It gives the design team a concrete decision context and gives the company a useful way to review the result.

### What should be checked before approval?

Check the source record, rendered page, links, responsive behavior, and the facts or decisions that the page presents.
