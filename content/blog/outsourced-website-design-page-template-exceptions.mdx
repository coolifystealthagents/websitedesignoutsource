# Managing Template Exceptions with an Outsourced Website Design Team

Reusable page templates save repeated decisions, but forcing every page into one shape can make important content harder to use. The handoff needs a rule for exceptions.

## Start with the visitor task

Describe what the page must help someone do and which template element gets in the way. A long comparison, a technical resource, and a short service page may need different content order even when they share a header and footer.

## Choose the smallest exception

Change one section before proposing a new template. If the exception affects navigation, headings, forms, or mobile order, show the behavior at representative widths. A screenshot alone cannot explain how the page should behave when labels wrap or content grows.

## Record the maintenance cost

Name the new rule, affected routes, owner, and review trigger. If a new pattern will be reused, document it as a component. If it is truly unique, keep its source close to the page and explain why reuse would be misleading.

## Approve the boundary

The company owner approves whether the exception is a content need or a visual preference. The outsourced website design team can explain the implementation tradeoff and update the source record after approval. This keeps a one-page request from creating an accidental second system.
