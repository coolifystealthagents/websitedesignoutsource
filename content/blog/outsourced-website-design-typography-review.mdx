# Review Typography as a Website Design Handoff Detail

Typography affects comprehension, hierarchy, and the space available to every component. It deserves a clear review record when an external team hands over website designs.

## Record the type rules

List families, weights, sizes, line heights, and intended uses. Separate semantic roles such as heading, body, label, and caption from their raw visual values.

## Test realistic content

Use the longest approved headings, names, navigation labels, and error messages. Check whether wrapping preserves meaning and whether the layout remains balanced.

## Check reading conditions

Review zoom, narrow screens, contrast, focus, and line length. A type choice that looks strong in a presentation may fail in the actual route.

## Preserve licensing and fallback behavior

Record the source and permitted use of each font, plus the fallback stack. The implementation should remain legible if a font cannot load.

## Frequently asked questions

### Should typography be approved before content?

Review type with representative content. Final approval should consider both the rules and how real copy behaves in the layout.

### What belongs in the fallback record?

Include the fallback family, any expected metric differences, and the routes that should be checked when the primary font is unavailable.
