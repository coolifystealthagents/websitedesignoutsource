# Setting Content Reuse Boundaries in an Outsourced Website

Mark which statements are shared foundations, which are audience-specific, and which must be written for one page. Keep source ownership clear for facts that appear in multiple places.

## Control divergence

When a shared statement changes, list every page that uses it and review the surrounding context. A sentence can remain accurate while becoming misleading in a different section.

## Review the reading experience

Check repeated headings, duplicate search intent, and pages that feel interchangeable. Reuse language where it helps recognition, then give each page a distinct reason to exist.

## Frequently asked questions

### Why include this in an outsourced design brief?

It gives the design team a concrete decision context and gives the company a useful way to review the result.

### What should be checked before approval?

Check the source record, rendered page, links, responsive behavior, and the facts or decisions that the page presents.
