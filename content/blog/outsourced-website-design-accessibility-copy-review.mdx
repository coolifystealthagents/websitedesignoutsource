# Accessibility Copy Review for an Outsourced Website

Review headings for a logical outline, link text for destination clarity, labels for form fields, and error messages for recovery guidance. These are content decisions as much as interface decisions.

## Remove hidden assumptions

Do not rely on color, position, or visual emphasis alone to explain meaning. State the relevant condition in text and keep instructions close to the control they describe.

## Pair copy with interaction tests

Read the page with keyboard navigation and a screen reader where possible. Check that the spoken sequence matches the visible sequence and that errors identify how to recover.

### Why include this in an outsourced design brief?

It gives the design team a concrete decision context and gives the company a useful way to review the result.

### What should be checked before approval?

Check the source record, rendered page, links, responsive behavior, and the facts or decisions that the page presents.
