# A Content Approval Gate for Outsourced Website Design

Visual review cannot repair an unsupported claim or an incomplete page goal. A content gate gives the page owner a chance to settle meaning before the outsourced website design team spends time on fine layout decisions.

## Approve the page job

Confirm the audience, visitor task, main heading, supporting content, action, required links, and factual owner. If any of these are unknown, mark the page as discovery rather than pretending the design brief is ready.

## Review content in the layout

Once copy is placed, check headings, link labels, field instructions, image alternatives, and long text. The owner should review the actual page shape because a sentence that reads well in a document can create a poor hierarchy in the design.

## Separate changes by cause

Record whether a revision fixes a factual issue, a task problem, a responsive issue, or a preference. This helps the outsourced website design team make the next draft without reopening decisions that were already accepted.

## Close with a named approval

The page owner approves the content version and lists open items. The designer records the visual version and source location. Keep both approvals together so future edits do not confuse a layout signoff with permission to change the page's meaning.
