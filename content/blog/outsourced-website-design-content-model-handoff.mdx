# Content Model Handoff for Outsourced Website Design

When several pages share a shape, the design team needs to know which parts are fixed, which parts vary, and which fields can be missing. A content model note answers those questions before templates become brittle.

## List fields by purpose

For each field, record its meaning, expected length, required status, and owner. A title, summary, eyebrow, image alternative, and action label should not be treated as interchangeable text boxes. The field name should describe the content job.

## Show ordinary and difficult examples

Give the outsourced website design team a short example, a long example, and a missing-value example. Review how the layout responds when text wraps, an image is unavailable, or a related link is not present.

## Separate content from decoration

If a visual treatment depends on a field, state the rule. Do not ask a template to infer importance from punctuation or word count. The page owner decides what the content means; the designer recommends a readable presentation.

## Preserve the handoff

Return the field list, examples, template reference, and approval note with the source files. When a new field is proposed, record which existing pages it affects. That keeps a later content request from turning into an unreviewed template change.
