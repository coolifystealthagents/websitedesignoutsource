# Add Skip Links to the Website Handoff

**Published: September 10, 2026**

A skip link saves keyboard users from moving through repeated navigation on every page. It needs a real destination and predictable focus behavior, not merely a hidden anchor near the top of the markup.

## Define the destination

Identify the main-content container in the component specification. If a page has persistent filters or a long local menu, decide whether it needs another skip destination. Labels should describe where each link goes.

## Specify focus and visibility

The link should become visible when focused and remain readable over the header. After activation, keyboard focus must move to the intended region so the next Tab press continues inside it. Account for sticky headers that could cover the target.

## Capture acceptance evidence

Start at the address bar, press Tab, and record the first interactive target. Activate the skip link on representative templates, then note the focused element and its visible position. Repeat at a narrow viewport and after client-side navigation.
