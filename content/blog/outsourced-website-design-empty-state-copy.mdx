# Empty-State Copy for Outsourced Website Design Projects

An empty state is part of the page design, not a temporary message to write after the layout is finished. It tells the visitor what happened and whether there is a useful next step.

## Name the cause

Separate no results, not-yet-available content, an empty account, and a failed request. Each state needs different wording. Do not tell a visitor that nothing exists when the system simply could not load the content.

## Give the message a job

Write a short explanation, the recovery action, and any condition that must be met first. If the visitor can change a filter, say what to try. If an owner must add content, do not imply that the visitor caused the problem.

## Design for real length

Provide the longest approved message to the outsourced website design team. Check the icon or illustration's relationship to the text, keyboard focus on the action, and the state at a narrow width. Avoid making the empty state depend on color alone.

## Record responsibility

The product or content owner approves the meaning of the message. The design team documents the visual treatment, interaction, and fallback behavior in the handoff. Keep the empty state beside the ordinary state so future reviewers remember both.
