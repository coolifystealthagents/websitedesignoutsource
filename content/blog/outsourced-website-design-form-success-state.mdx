# Designing a Clear Form Success State for an Outsourced Website

State whether the submission was received, what the visitor should expect, and where they can continue browsing. Keep the message specific to the form's purpose and avoid implying a response time that is not established.

## Cover recovery paths

Define what happens after a refresh, a repeated submission, a validation error, or a slow response. Make it possible to understand the result without relying on a transient color change.

## Test the full journey

Review keyboard focus, announced status, confirmation content, and mobile layout. Verify that the success state does not expose private details or create a dead end.
