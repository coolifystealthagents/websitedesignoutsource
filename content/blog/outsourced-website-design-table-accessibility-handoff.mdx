# Hand Off Data Tables With Their Reading Relationships

**Published: September 11, 2026**

A visual grid is not enough to communicate data relationships. Table handoff should preserve the meaning of rows, columns, groups, abbreviations, and totals.

## Define the structure

Provide a caption or nearby name, row and column headers, header scope, units, footnotes, and the source of each value. Complex spanning headers need an explicit reading plan.

## Choose a narrow-screen pattern

Decide whether the table scrolls, simplifies, or offers another view. Keep headers available and avoid turning data into unlabeled cards. Provide a download only as a supplement to usable page content.

## Verify relationships

Navigate cells with a screen reader, zoom the page, test long values, and inspect printed output. Confirm sorting controls expose their name and current direction.
