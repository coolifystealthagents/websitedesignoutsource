# A Design Review Agenda for Outsourced Website Design

Review meetings drift when content, visual taste, route safety, and implementation questions arrive at once. A short agenda gives each question a place and leaves the outsourced website design team with decisions it can use.

## Start with the page goal

Read the visitor task, audience, approved promise, and primary action. Confirm that the page being reviewed is the one in the brief. If the goal has changed, pause visual review and record the new decision.

## Inspect structure before polish

Review heading order, content sequence, links, actions, and required states. Then inspect responsive layout, keyboard path, assets, metadata, and source files. This order catches expensive changes before small visual preferences take the meeting.

## Consolidate decisions live

For each issue, record route, location, expected result, owner, and status. Separate a required correction from a preference or new request. The outsourced website design team should leave with one list, not several private comment threads.

## End with acceptance boundaries

Name what is accepted, what remains open, and what is outside the current review. Set the next decision owner and source location. A useful agenda ends in a record that another person can read without attending the meeting.
