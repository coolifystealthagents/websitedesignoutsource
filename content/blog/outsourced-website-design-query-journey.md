# Mapping a Query Journey for Outsourced Website Design

A query journey connects a search question to the information, evidence, and next step a visitor needs on a website.

## Start with the visitor question

Describe the problem behind the query and the decision the visitor may be trying to make. Keep the page promise narrower than a list of every related topic.

## Plan the answer sequence

Order explanation, examples, qualifications, and next steps so each section resolves a question raised by the one before it.

## Link to the next useful question

Use contextual internal links when a visitor may need a deeper guide. The linked page should continue the journey instead of sending the reader to an unrelated destination.

## Frequently asked questions

### Is a query journey the same as a keyword list?

No. It describes visitor needs and page decisions rather than collecting phrases without a content purpose.

### How should the page be reviewed?

Check the promise, answer sequence, supporting evidence, links, and next step against the visitor question the page intends to serve.
