# Govern Download Links in Website Production

**Published: September 11, 2026**

Downloads become stale when the page and file follow separate approval paths. A register connects each public link to a current, owned source file.

## Record file identity

Capture the public label, route, filename, format, size, language, revision date, source owner, and retention rule. State whether access requires authentication and whether the file contains sensitive data.

## Set replacement rules

Decide when a stable URL serves a new revision and when a new URL is required. Keep page claims, file contents, metadata, and revision notes aligned. Provide an accessible HTML alternative when feasible.

## Audit the delivery

Open each link without an editor session. Verify status, content type, filename, file integrity, mobile behavior, keyboard access, and removal of superseded documents.
