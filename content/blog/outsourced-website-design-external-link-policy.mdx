# Set an External Link Policy People Can Actually Review

**Published: September 9, 2026**

Outbound links connect a maintained website to destinations the delivery team does not control. A small policy keeps those decisions consistent without pretending every link is permanent.

## Record purpose and owner

For each important destination, capture why it is linked, who approved it, expected audience, review trigger, and whether an internal alternative exists. The designer should not endorse a vendor merely because its logo fits the layout.

## Make behavior predictable

Use descriptive labels. Open in the same context by default unless a documented workflow needs another choice. If a new context is required, communicate it accessibly and apply the approved security attributes.

## Maintain the route set

Check status, redirects, destination identity, protocol, and surrounding claims on a schedule proportionate to risk. A successful response is not proof that the page still supports the original purpose.
