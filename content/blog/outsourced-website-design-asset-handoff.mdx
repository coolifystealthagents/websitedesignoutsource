# Prepare an Asset Handoff for Outsourced Website Design

An asset folder without context creates avoidable questions. A useful handoff connects each image, logo, icon, or font to its purpose, permission, and owner.

## Give each asset an identity

Use a clear filename and record what the asset shows, its intended page, crop guidance, alternative text, and source. Keep the original file when it may be needed later.

## Record usage rights

State the license or approval record and any restrictions. The designer should not have to infer whether a file can appear on a public page.

## Separate approved from exploratory files

Use folders or a simple status field. An attractive draft can easily be mistaken for the chosen asset when both have similar names.

## Check the rendered result

Review the crop, focal point, contrast, loading treatment, and alternative text in the page. Asset approval is about the asset in context, not only the source file.

## Frequently asked questions

### Should the designer choose stock imagery?

Only when that responsibility is explicit and the license record is retained. The brief should state whether new imagery is allowed.

### Who approves alternative text?

The person who understands the image's purpose and audience should approve its meaning. A technical reviewer should check that the text is attached correctly.
