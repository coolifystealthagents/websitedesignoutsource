# Writing a Useful Title and Description Brief for Web Design Pages

Record the page audience, search question, primary subject, preferred title, description draft, canonical route, and internal links. Treat the title and description as accurate summaries, not detached advertising lines.

## Avoid duplicate promises

Compare neighboring pages before finalizing metadata. Similar titles can make a site difficult to understand, while an overly broad description can attract the wrong visitor.

## Validate the rendered page

Check the source values, canonical URL, visible heading, and structured metadata together. A correct field is not enough if it describes a different page than the one visitors see.

## Frequently asked questions

### Why include this in an outsourced design brief?

It gives the design team a concrete decision context and gives the company a useful way to review the result.

### What should be checked before approval?

Check the source record, rendered page, links, responsive behavior, and the facts or decisions that the page presents.
