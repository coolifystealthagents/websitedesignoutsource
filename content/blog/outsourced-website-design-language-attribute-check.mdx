# Check Page Language in an Outsourced Website Handoff

**Published: September 11, 2026**

Language metadata helps browsers and assistive technology interpret words correctly. It should follow the approved content and localization plan.

## Name the default language

Record the primary language for each template and localized route family. Decide how mixed-language names, quotations, and interface fragments are marked when pronunciation rules change.

## Align routing and metadata

Check that the HTML language value, visible copy, canonical URL, alternate-language links, title, and navigation agree. Do not infer a language solely from a visitor's location.

## Test representative pages

Inspect the rendered root element and inline language changes. Review a long article, a form, an error state, and a localized navigation path with pronunciation support enabled.
