# When to Include a Design Token Brief in Outsourced Website Design

Start with the decisions that repeat across page types. Name the role of a color or spacing step instead of documenting only a raw value.

## Make the decision visible

Keep exceptions visible. A token system should make common choices easy without hiding why a special component needs different treatment.

## Review the real page

Ask for examples in a header, card, form, and mobile layout. The point is to see whether the system supports real pages, not to collect a long list of numbers.

## Keep the handoff useful

A shared token brief helps an external design team produce consistent screens and helps your reviewer identify a real system break during acceptance.

## Frequently asked questions

### What should the brief include?

Include the visitor, page purpose, approved evidence, required states, owner, and the decision the reviewer must make.

### Who should approve the design?

Name one person inside the company who can approve the content, page behavior, and final handoff.
