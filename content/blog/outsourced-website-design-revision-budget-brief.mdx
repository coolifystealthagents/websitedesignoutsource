# How to Write a Revision Budget Brief for Outsourced Website Design

Revision time disappears when every comment looks equally urgent. An outsourced website design brief should separate corrections, decisions, and new requests before the next draft begins.

## Classify each comment

Label a note as a brief correction, content change, usability issue, visual preference, or new scope. This is not a billing exercise. It tells the designer whether to fix an agreed requirement, ask for an owner decision, or pause until the page goal changes.

## Tie comments to evidence

Each note should name the route, section, viewport, and expected result. Replace "make this clearer" with a sentence such as "the primary action should be understandable before the visitor scrolls." Include a screenshot only when it helps locate the issue. The working page remains the source for interaction feedback.

## Protect the next draft

Choose a small set of changes that can be reviewed together. If the page still lacks approved copy or a clear audience, do not bury that problem beneath color tweaks. Record unresolved decisions separately so the outsourced website design team does not guess at them.

## Close the loop

Return one consolidated review with an owner for each decision. The next handoff should state what changed, what stayed, and what still needs approval. A short revision record gives both sides a stable reference when a later request touches the same section.
