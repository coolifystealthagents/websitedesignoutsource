Autofill Token Acceptance for Website Forms treats autofill tokens as an observable client acceptance question, not a screenshot preference. At checkpoint 1, identify identity and checkout fields, the approved requirement, affected route, viewport or input state, expected result, and form owner. Record WD-B-outsourced-website-autofill-token-acceptance-1 so another reviewer can repeat the decision.
