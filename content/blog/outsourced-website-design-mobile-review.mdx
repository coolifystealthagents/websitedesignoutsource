# Run a Mobile Review of Outsourced Website Design

Reviewing a narrow layout means checking what the visitor can do, not just whether the desktop design became smaller. Use the real route and real content.

## Start with the main task

Confirm that the first useful action is visible and understandable. Check heading order, supporting copy, links, forms, and any content that was moved below the fold.

## Test the awkward states

Use long labels, wrapped buttons, errors, missing images, enlarged text, and a keyboard where relevant. These cases reveal whether the layout rules are real.

## Record the environment

Note the route, browser or device, viewport, test content, issue, and owner. A short evidence note is more useful than a general claim that mobile was checked.

## Review the fix in context

Check adjacent sections after a change. A local spacing fix can alter the page's reading order or make the next action harder to find.

## Frequently asked questions

### Is a screenshot enough for mobile review?

It can show a visual issue, but interaction and text behavior need the actual page or an equivalent test environment.

### Who fixes a mobile issue?

Assign the owner based on the cause. It may be content, design, asset, or implementation work.
