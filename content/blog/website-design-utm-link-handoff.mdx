# Prepare a UTM Link Handoff for Website Campaigns

**Published: September 2, 2026**

Campaign links become hard to compare when each contributor invents capitalization, spacing, and parameter names. A link handoff should connect the published destination to an agreed naming system and a responsible reporting owner.

## Establish a naming register

Define allowed values and formatting for source, medium, campaign, content, and any organization-specific fields. Include plain-language definitions, examples, prohibited data, and who approves new values. Keep the register in a client-owned location.

## Build links from final destinations

- Start with the canonical HTTPS route.
- Add only parameters required by the measurement plan.
- Check encoding and letter case.
- Avoid personal or confidential information.
- Record the channel, owner, and publication date.

## Test the complete journey

Open each link, confirm the intended page returns successfully, and check that redirects preserve or intentionally transform parameters. Verify the expected campaign record using non-production or controlled test traffic. A working URL does not by itself prove useful reporting.

## Manage later changes

If a destination moves, update campaign sources where possible and maintain the redirect map. Document how duplicate variants are corrected and how expired campaigns are treated. Reporting definitions and privacy decisions stay with the client.

## Frequently asked questions

### Should UTM values contain customer names?

Avoid personal or confidential data. Have the client privacy owner approve the naming policy.

### Who maintains the register?

Assign one client-side measurement owner, even when agencies generate links.
