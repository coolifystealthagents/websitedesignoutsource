# A Redirect Testing Plan for an Outsourced Website Redesign

Build a source-to-destination table with reason, status code expectation, canonical destination, and owner. Include old campaign links, common variants, and routes discovered outside the main navigation.

## Test for intent

A redirect is successful when it reaches the right equivalent page, not merely when it returns a response. Review chains, loops, irrelevant destinations, and changes that discard important query behavior.

## Keep a review record

Record test date, source, destination, result, and follow-up. Recheck the map when page names or information architecture change late in the project.

## Frequently asked questions

### Why include this in an outsourced design brief?

It gives the design team a concrete decision context and gives the company a useful way to review the result.

### What should be checked before approval?

Check the source record, rendered page, links, responsive behavior, and the facts or decisions that the page presents.
