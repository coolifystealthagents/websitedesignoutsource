# Give Every Website Download a Useful Filename

**Published: September 9, 2026**

The page label may disappear once a file reaches a downloads folder. A useful filename carries enough identity for the visitor to recognize it later.

## Define the file record

Provide the visible link label, approved filename, format, language, version or effective date, approximate size, source owner, and replacement rule. Avoid vague names such as `final-2.pdf` and do not expose internal client codes.

## Set expectations before activation

Tell visitors when a link downloads a file, opens a document, or leads to another page. State file type and size when that knowledge changes the decision. Keep the link purpose understandable outside its surrounding card.

## Inspect the saved result

Request the asset directly, activate it by keyboard, and compare response headers, displayed facts, saved filename, and actual format. Check stale links after replacement and confirm the old asset policy with the content owner.
