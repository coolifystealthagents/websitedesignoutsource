# Font Loading Handoffs for Outsourced Website Design

Typography decisions affect brand, layout, and loading behavior. An outsourced handoff becomes safer when it documents font sources, permitted weights, fallback metrics, loading strategy, and what happens when a font is unavailable.

## Research basis

CSS Fonts and CSS Font Loading define how fonts are declared and observed, while the W3C Web Performance Working Group documents the user experience implications of loading resources. The review should treat fallback layout as a designed state, not a failure hidden by a screenshot.

## Handoff evidence

List each family and weight, its license source, preload or loading decision, fallback stack, and tested language coverage. Review headings, navigation, buttons, and long-form content before and after the custom font is available.

## Frequently asked questions

### Is a font preview enough for approval?

No. Approval should include the actual loading and fallback states, plus licensing and language coverage appropriate to the site.

### Can a fallback change the layout?

Yes. Different metrics can alter wrapping and component height, which is why representative content should be tested with the fallback stack.
