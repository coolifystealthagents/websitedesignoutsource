# SEO Briefs for Outsourced Web Content

An SEO brief should help a writer answer a user’s question and help an editor verify the page. It should not be a list of keywords detached from audience, evidence, or page purpose.

## Brief fields

Define audience, search intent, primary question, supporting questions, evidence needs, internal links, title direction, page type, author or reviewer, and acceptance checks. Keep claims traceable to sources.

## Methodology

This synthesis uses search guidance and editorial standards. Search documentation changes, so teams should revisit the linked guidance during each planning cycle.

## Key Stats

- Google says its systems prioritize helpful, reliable, people-first content (Google)
- Schema.org provides a shared vocabulary for structured data (Schema.org)

## Key Takeaways

- Start with user intent and evidence.
- Use internal links to clarify the site’s information structure.
- Review claims, metadata, and accessibility together.

## Frequently asked questions

### Should a brief prescribe a keyword count?

No. It should define the user need, coverage, evidence, and quality bar.

### Who verifies sources?

The named editor or subject-matter reviewer should verify material claims before approval.
