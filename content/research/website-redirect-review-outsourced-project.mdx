# Redirect Review for an Outsourced Website Project

Redirect work is a content and infrastructure handoff. The safest review starts with a complete old-URL inventory, maps each retained or changed page, and tests the result before the company owner approves release.

## Mapping table

| Old URL state | Decision | Evidence |
| --- | --- | --- |
| Same purpose | Keep URL | Page review |
| Renamed purpose | Map to closest useful page | Redirect test |
| Removed content | Confirm destination or removal | Owner decision |
| Unknown | Investigate before release | Crawl and log |

## Methodology

This synthesis uses Google’s site-move guidance, RFC 9110, the sitemap protocol, Search Central’s SEO guidance, W3C, OWASP, NIST, and Git references. The numeric statements describe standards only. Recommendations are for a company that retains final control while an external team implements the change.

## Key Stats

- HTTP 3xx responses represent redirection (IETF RFC 9110)
- WCAG 2.2 has 4 principles (W3C)

## Key Takeaways

- Map URLs before deleting or renaming pages.
- Test chains, loops, destinations, and canonical signals together.
- Keep the redirect inventory and approval in the company workspace.

## Review sections

### URL inventory

Export the current route list from the repository, sitemap, analytics, and link sources available to the company. Mark each route as kept, redirected, consolidated, or investigated. Do not treat a missing sitemap entry as proof that a URL has no value.

### Redirect behavior

Google recommends permanent server-side redirects for lasting moves and a direct mapping to the new destination. Test the response, final URL, content purpose, canonical, and internal links. A chain can hide an incorrect mapping even when the browser eventually reaches a page.

### Release evidence

Save the old URL, expected destination, observed status, date, tester, and exception. The delivery team can prepare the map and tests. A company owner should approve the risk of removing, merging, or redirecting pages.

## Frequently asked questions

### Should every old URL redirect to the home page?

No. Map a changed URL to the closest useful destination. A generic home-page redirect can discard the old page’s purpose and confuse visitors.

### Who approves URL removal?

The company owner should approve removal after reviewing search, analytics, links, and business purpose. The external team should record the evidence.
