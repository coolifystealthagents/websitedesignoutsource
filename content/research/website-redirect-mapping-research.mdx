# Redirect Mapping as a Website Research Task

Redirects are not a clerical afterthought. They preserve useful paths, clarify content decisions, and give reviewers a concrete migration artifact.

## Build the map

Export known URLs, classify their purpose, choose a destination or retirement decision, and record confidence and owner. Test exact path behavior, query handling, chains, loops, and representative old links after implementation.

## Methodology

This synthesis uses search and HTTP standards documentation. It does not predict rankings or decide which content a business should retain.

## Key Stats

- HTTP defines 3xx status codes for redirection (IETF)
- Google documents 301 and 308 redirects as permanent redirects (Google)

## Key Takeaways

- Map URLs before implementation.
- Prefer one direct, relevant destination.
- Test both expected redirects and accidental chains.

## Frequently asked questions

### Should redirects point to the home page?

Only when it is genuinely the closest useful destination. Broad irrelevant redirects create a poor user experience.

### What is a redirect chain?

A sequence where one redirect points to another. Direct mappings are easier to test and maintain.
