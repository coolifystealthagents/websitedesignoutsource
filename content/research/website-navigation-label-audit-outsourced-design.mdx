# Navigation Label Audits for Outsourced Website Design

Navigation labels are promises about where a user will go. A label audit checks those promises against page purpose, information architecture, accessible names, and the words customers use when looking for a service.

## Research basis

W3C guidance treats links and headings as structural and interactive content, while information-architecture research emphasizes labels that are understandable before activation. An outsourced review should therefore test both the visible menu and the underlying heading and link structure.

## Review method

Create a route-to-label table. For each item, record its destination, visible label, accessible name, parent context, and expected user question. Flag labels that are vague, duplicated without context, or different across navigation, breadcrumbs, cards, and page titles.

## Frequently asked questions

### Should every menu label match a page title?

Not necessarily. It should be recognizable and consistent with the destination, while the page title can carry more specific context.

### Is a visual review enough?

No. Inspect the rendered interaction and the semantic structure so keyboard and assistive-technology users receive the same information.
